# Bimatiq GitHub Brand Standard

## Authority

The live Notion Brand Identity System controls visual rules.

Drive stores approved master brand files.

GitHub stores repository presentation assets.

The identity is currently at Version 2 definition stage. GitHub graphics are implementation assets, not final master artwork.

## Identity

Use lowercase `bimatiq` in logo artwork.

Do not recreate the logo by typing the name.

The old modular BIQ letter mark is retired. The square pattern carries the modular idea.

## Colours

Charcoal `#1D2D35`

Teal `#21877D`

Coral `#E76F51`

Warm off white `#F7F7F5`

White `#FFFFFF`

Secondary text `#5A6B73`

Accessible teal text `#17635B`

Hairlines `#E3E7E8`

Coral is an accent only and is never used for body text.

## Typography

Use Comfortaa 600 for display graphics.

Use IBM Plex Sans for supporting text.

Use IBM Plex Mono for code and technical labels.

Normal README paragraphs use GitHub typography.

Do not commit font files.

## Header

Use the lowercase wordmark, warm off white background, charcoal and teal as dominant colours, thin structural rules and the square pattern.

Keep coral restrained.

Do not add buildings, gears, circuits or gradients.

## Badges

All technology badges use one construction.

1. Same dimensions.
2. Charcoal background.
3. Teal edge.
4. One coral square.
5. White label.
6. Comfortaa 600 where supported.
7. No vendor icons unless a later controlled rule requires them.

Current badges are Revit, C Sharp, Python, Dynamo, Practical AI and Git.

## Diagrams

Use warm off white, charcoal, teal, coral accents and light grey structural lines.

The standard automation method is `Understand → Structure → Automate → Validate → Improve`.

## README standard

Start new Bimatiq repositories from `templates/PROJECT_README_TEMPLATE.md`.

Explain the workflow before the technology.

Use accurate status language such as `Concept`, `Prototype`, `Validation`, `Active development` and `Production`.

Never describe a prototype as a production system.

## Accessibility

Use charcoal for normal text on light backgrounds.

Use `#17635B` when teal is required for normal sized text.

Do not use coral for text.

Keep important information in normal README text as well as graphics.

Use useful alternative text for every image.
